# 🙌 Track General

## 🎯 De qué se trata
El Track General es el track abierto. Podés construir lo que quieras, siempre que resuelva algo concreto del sector agropecuario: una app para el productor, una herramienta para el técnico de campo, un sistema de monitoreo, un dispositivo o un prototipo armado sin código.

## 🧑‍💻 Casos de uso
- **Trazabilidad y origen.** Registrar cada etapa del recorrido de un producto (siembra, cosecha, acopio, transporte y venta) para certificar su origen, cumplir exigencias de mercados de exportación o darle al comprador información verificable.
- **Clima y gestión del riesgo.** Alertas tempranas de heladas, granizo, sequía o exceso hídrico, herramientas para decidir fechas de siembra o cosecha con datos meteorológicos, o sistemas que ayuden a estimar daños.
- **Gestión del campo.** Apps o tableros para registrar labores, insumos y costos por lote, planificar rotaciones o reunir datos que hoy quedan repartidos entre cuadernos, planillas y chats de WhatsApp.
- **Sanidad de cultivos y monitoreo.** Detección de plagas, malezas o enfermedades a partir de fotos con el celular, imágenes satelitales o de drones, sensores de humedad de suelo, o sistemas para registrar y reducir el uso de agroquímicos.

## ✅ Qué hace fuerte a un proyecto (criterio del jurado)
> Resuelve un problema que un productor, un técnico o una empresa del sector reconocería como propio, y el equipo puede explicar a quién le sirve y por qué lo usaría.
