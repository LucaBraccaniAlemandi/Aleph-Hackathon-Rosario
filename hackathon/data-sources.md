# Fuentes de datos

| Fuente | Qué da | Tracks | Acceso |
|---|---|---|---|
| [OpenStreetMap](https://www.openstreetmap.org) | Rutas y caminos rurales | Log | Datos abiertos |
| [Overpass Turbo](https://overpass-turbo.eu) | Consultas a OSM (ej. caminos de tierra por departamento) | Log | API pública, sin key |
| [OSRM](https://project-osrm.org) | Ruteo y tiempos de viaje | Log | API demo pública / self-host |
| [Open-Meteo](https://open-meteo.com) | Lluvia acumulada, pronóstico, histórico | Log, Fin, Gen | API sin key |
| [Copernicus Browser](https://browser.dataspace.copernicus.eu) | Imágenes Sentinel, anegamientos, NDVI | Log, Gen | Cuenta gratuita |
| [Google Earth Engine](https://earthengine.google.com) | Catálogo satelital + análisis | Gen | Cuenta (registro) |
| [BCR — Informativo Semanal](https://www.bcr.com.ar) | Cosecha, logística, puertos del Gran Rosario | Log | Web / PDF |
| [BCR — Cotizaciones](https://www.bcr.com.ar) | Precios de granos mercado local | Fin | Web |
| [A3 Mercados](https://www.a3mercados.com.ar) | Futuros y opciones de granos (ex Matba Rofex) | Fin | Web / API |
| [APIs del BCRA](https://www.bcra.gob.ar) | Tipo de cambio, tasas, indicadores | Fin | API pública |
| [Estimaciones Agrícolas (MAGyP)](https://datosestimaciones.magyp.gob.ar) | Producción, superficie, rindes por cultivo y departamento | Log, Fin, Gen | CSV |
| [datos.gob.ar](https://datos.gob.ar) | Datos abiertos del Estado (agroindustria) | Gen | CSV / API |
| [PlantVillage](https://plantvillage.psu.edu) | Dataset de hojas sanas/enfermas | Gen | Dataset |
| [INTA](https://www.argentina.gob.ar/inta) | Informes técnicos | Gen | Web / PDF |

> Links tomados de conocimiento general, no verificados todavía. Verificar antes de usarlos.
